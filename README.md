## 🚀 Local Development

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Yashashvi211189/star-wars-portfolio.git
   cd star-wars-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Start backend server** (optional)
   ```bash
   npm run server
   ```

5. **Run both frontend and backend**
   ```bash
   npm run dev:full
   ```

## 📦 Build & Deploy

### Build for Production
```bash
npm run build
```

### Deploy to GitHub Pages
```bash
npm run deploy
```
