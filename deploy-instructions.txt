DEPLOYMENT INSTRUCTIONS FOR STAR WARS PORTFOLIO
================================================

STEP 1: Create GitHub Repository
-------------------------------
1. Go to GitHub.com and sign in
2. Click "New repository"
3. Repository name: star-wars-portfolio
4. Make it Public
5. DO NOT initialize with README
6. Click "Create repository"

STEP 2: Connect Local Repository to GitHub
-----------------------------------------
# Replace YOUR_USERNAME with your GitHub username
git remote add origin https://github.com/YOUR_USERNAME/star-wars-portfolio.git
git branch -M main
git push -u origin main

STEP 3: Enable GitHub Pages
---------------------------
1. Go to your repository on GitHub
2. Click "Settings" tab
3. Scroll down to "Pages" in left sidebar
4. Under "Source", select "GitHub Actions"
5. The GitHub Action will automatically deploy your site

STEP 4: Access Your Live Website
--------------------------------
Your website will be available at:
https://YOUR_USERNAME.github.io/star-wars-portfolio/

ALTERNATIVE MANUAL DEPLOYMENT:
=============================
If you prefer manual deployment:

1. Build the project:
   npm run build

2. Deploy to GitHub Pages:
   npm run deploy

3. In repository settings > Pages:
   - Source: "Deploy from a branch"
   - Branch: "gh-pages"
   - Folder: "/ (root)"

LIVE WEBSITE WILL BE:
https://YOUR_USERNAME.github.io/star-wars-portfolio/
